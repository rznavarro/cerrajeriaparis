# Carpeta para el Logotipo de Cerrajería París

Guarda aquí el archivo de tu logotipo oficial.

### Instrucciones:
1. Puedes nombrarlo preferentemente:
   - `logo.png`
   - `logo.svg`
   - `logo.webp`
2. Si usas cualquiera de estos nombres estándar o una ruta personalizada, la página web lo cargará automáticamente en la barra superior (Header) y en el pie de página (Footer).
3. Para ajustar el nombre o ruta del archivo, puedes editar la propiedad `logoUrl` en `src/business.config.ts`.
   Ejemplo:
   ```ts
   logoUrl: "/logo/logo.png"
   ```
